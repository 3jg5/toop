# Midmak — Brand & Logo Notes

**Name.** مِدماك / Midmak. In Arabic, *midmak* (مِدماك) is a **course — one horizontal row of bricks** laid in a wall. The leaf above the bricks adds the sustainability idea.

## Files (brand/)
| File | Use |
|---|---|
| `midmak-logo-vertical-ondark.svg` | Primary lockup for dark backgrounds (white type, transparent) |
| `midmak-logo-vertical-onlight.svg` | Same lockup for white/light backgrounds (dark type) |
| `midmak-logo-horizontal-ondark.svg` / `-onlight.svg` | Header, letterhead, signage (icon right, Arabic over English, RTL reading) |
| `midmak-logo-vertical-ondark-bg.svg` | Lockup with the brand dark background baked in (avatars, social) |
| `midmak-icon.svg`, `midmak-icon-app.svg` | Icon only; app icon with rounded dark square |
| `png/` | Transparent PNGs at 2000 px and 600 px wide + app icon 1024 px |
| `eps/` | Print vector (EPS 3.0) for the on-light, horizontal, icon and dark-background versions |
| `../icons/` | PWA icons (192, 512, maskable 512) used by the manifest |

The lettering (Arabic *مِدماك* with the kasra, and Latin *Midmak*) is **outlined vector traced from the supplied artwork**; it is not live text, so no font is needed to open the files. Do not retype it.

## Typography
- **Logo type** is fixed artwork: a rounded, humanist Arabic sans (close to Noto Sans Arabic / Tajawal Bold) over a humanist Latin sans (close to Noto Sans / Segoe UI Regular). Keep the Latin as **"Midmak"** with a capital M, as in the supplied artwork.
- **Website companions:** **Cairo** (headings, 800–900) and **Tajawal** (body, 400–700), already loaded by the site; **Inter** for Latin-only documents.

## Construction and usage
- **Clear space:** at least the height of one brick (≈ 11 % of the vertical lockup width) on every side.
- **Minimum size:** horizontal lockup 140 px / 35 mm wide (below that the English line becomes illegible — use icon-only); vertical 90 px / 22 mm; icon 24 px.
- **Do not** recolour the icon bricks, stretch, rotate, add shadows, place the on-dark file on light backgrounds, or change the Arabic/English proportion.
- **Partner logos** (Ministry of Education, Al-Farouq School, Oman Vision 2040) keep their own artwork; place them on the light chips already used in the header.
